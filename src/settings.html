03 助手联动

你的 agent 忙起来，猫也会忙起来
LISTENING
127.0.0.1 :

本机的小小 webhook。coding agent 每完成一步，就发一条事件给 Tofu； 它会开始打字、检查，或者在你需要确认时抬头看你。

node bin/tofu-hook.mjs pre --tool edit
怎么接到 Claude Code？

在项目的 .claude/settings.json 里加入 hook，把事件 JSON 从 stdin 交给 tofu-hook --stdin 即可。完整示例见 docs/HOOKS.md。
